# 저평가 우량주 장기투자 워치리스트

싱글파이어 "오일전문가"편(4000만원 → 55억, **저평가+배당 우량주 장기 무매도**) 철학에 글로벌 IB 시각을 얹은 장기투자용 워치리스트입니다. `index.html`을 브라우저에서 열면 됩니다.

## 먼저 — 현실적인 눈높이

137배(4000만→55억)는 **장기(수년~10년+) × 집중 × 2020~2026 대세 상승장 × 무매도**가 겹친 결과입니다. 일반적 목표는 **연 10~15% 복리**(7~10년에 2~4배)가 현실적입니다. 핵심은 종목이 아니라 **"안 팔고 오래 버티는 것"**.

## 선정 기준 (동시 충족 지향)

1. PER 10배 이하
2. PBR 1배 이하 또는 업종 대비 저평가
3. ROE 10% 이상
4. 배당 3%+ 또는 자사주 소각(주주환원)
5. 3년 연속 흑자·낮은 부채

주의: 지표만 낮고 성장성이 없으면 "가치 함정". 저평가 **이유**(일시적 소외 vs 구조적 쇠퇴) 구분이 핵심.

### 저평가, 명확히 계산 (페이지 내 계산기)

리스트의 지표는 **대략치(참고용)**입니다. 페이지의 "저평가, 명확히 계산하기"에 실제 숫자를 넣으면 공식으로 판정합니다.

- PER = 현재가 ÷ EPS, PBR = 현재가 ÷ BPS, 배당률 = 배당 ÷ 현재가
- 정당PBR = ROE ÷ 요구수익률, 적정주가 = BPS × 정당PBR
- 안전마진 = 적정주가 ÷ 현재가 − 1 (양수면 저평가)
- 우량 게이트: ROE ≥ 10% · 부채 ≤ 100% · 흑자 (미달 시 지표 낮아도 "가치 함정")

## 장기투자 원칙

- 5~10종목 분산, 3년+ 보유, 하락장은 추가매수 기회
- 이익실현용 매도 자제(논리 훼손 시에만 매도), 배당 재투자
- 시드보다 꾸준함. 초보는 배당 ETF로 시작 후 개별주 확장
