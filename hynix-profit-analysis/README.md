### 결론 (위험선호별)
- **기대수익(평균) 최대화 → 끝까지 보유(2027 상반기)**. 강한 상승추세에서 평균 +0.79억으로 가장 높음. 단 최악 -0.32억.
- **현실적 결과(중앙값)·균형 → 익절 +50% 또는 분할매도**. 중앙값 +0.43억~+0.60억.
- **하방 방어 우선 → 트레일링 스톱 -15%**. 최악값을 -0.17억으로 개선.

### 권장 혼합 전략
9,500만원 규모의 단일종목 집중이므로:

1. **핵심 물량은 2026 하반기 촉매(2Q·3Q 실적, HBM4 양산)까지 보유**
2. **+30~50% 부근(≈315만~364만)부터 분할 익절**로 이익 확정
3. **트레일링 스톱 -15%로 하방 방어**
