# 하이닉스 향후 수입구간분석 · 이벤트 확률 예측

SK하이닉스 보유 포지션에 대한 두 가지 도구입니다.

1. **`index.html`** — 매도가별 세후 수익(수입구간) 계산기
2. **`forecast.html`** — 이벤트별 예상 시점·주가·확률(몬테카를로) 분석
