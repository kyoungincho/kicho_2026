# 하이닉스 향후 수입구간분석

SK하이닉스 보유 포지션에 대한 **미래 매도가별 세후 수익 시뮬레이션** 도구입니다.

## 입력 조건 (기본값)

| 항목 | 값 |
| --- | --- |
| 종목 | SK하이닉스 |
| 보유수량 | 42주 |
| 총매입금액 | 2,264,880원 |
| **평단가** | **53,926원** (= 2,264,880 ÷ 42) |
| 증권거래세(매도) | 0.15% |
| 매도수수료 | 0.015% |

> 입력값 해석: `42주`, `2264880평단`에서 총매입금액 2,264,880원을 보유수량 42주로 나눠
> 평단가 53,926원으로 계산했습니다. 웹 도구에서 수량·금액·세율을 자유롭게 수정할 수 있습니다.

- 평단이 53,926원으로 낮아, 현재가가 20만원대라면 이미 **+270% 내외의 세후 수익** 구간입니다.
- 매도가가 평단의 2배(약 107,900원)면 세후 약 **+226만원**, 4배(약 269,600원)면 세후 약 **+904만원**입니다.

## 사용법

브라우저에서 `index.html` 파일을 열면 됩니다. 별도 설치·빌드가 필요 없습니다.

```bash
# 로컬에서 바로 열기
open hynix-profit-analysis/index.html      # macOS
xdg-open hynix-profit-analysis/index.html  # Linux
```

- 보유수량 / 총매입금액 / 현재가 / 세율을 입력하면 요약·표·그래프가 실시간 갱신됩니다.
- 평단가는 `총매입금액 ÷ 보유수량`으로 자동 계산되며, 평단가를 직접 입력하면 총매입금액이 역산됩니다.

## 면책

본 도구는 투자 판단을 돕기 위한 계산기이며, 실제 수익을 보장하지 않습니다.
세율·수수료는 증권사와 시점에 따라 달라질 수 있으니 실제 값으로 조정해 사용하세요.
