## 최근 흐름 (2026)

6/23 사상 최고 300만원 터치 → 같은 날 급락 → 7/2 저점 218만원 → 현재 약 242만원.
**300만원은 미래 목표가 아니라 이미 찍고 내려온 전고점(사상 최고가)**입니다.

## 밸류에이션(PER) 반영 — 왜 더 오를 수 있나

주가 = 1년 예상 이익(주당 약 43만원, 한화 12개월 선행 EPS) × PER.
현재 PER은 약 5.6배로 마이크론 등 글로벌 반도체(10배 이상)의 반값 수준이고, 2분기 영업이익은 전년비 +589% 폭증. 이익 증가 + PER 재평가(리레이팅)가 겹치면 곱으로 오릅니다.

| 목표 PER | 예상 주가 | 내 손익(42주, 세후) |
| ---: | ---: | ---: |
| 5.6배 (지금) | 242만 | +674만 |
| 7배 (신중) | 301만 | +3,102만 |
| 10배 (증권가·한화 목표) | 430만 | +8,508만 |
| 12배 (강세·노무라급) | 516만 | +1.21억 |

근거: 한화 목표 430만 = 선행 EPS 42.98만 × 목표 PER 10배. 노무라 500만. ADR 나스닥 상장은 글로벌 비교를 통한 리레이팅 촉매. EPS는 2027년 46만원+로 더 커져 같은 PER이어도 주가는 더 오를 수 있음.

## 실제 일봉 (2026 5~7월) 반영

- 5월초 약 160만 → 6/22 고점 292만 = +82% (약 7주) → 7/2 저점 219만 = −25% (2주) → 현재 242만
- 일 변동성 ±8.2%(연 약 129%), 하루 최대 −14.6% / +16%
- 시사점: 이 종목은 몇 주 만에 +80%도, −25%도 가는 초고변동 종목. 전고점까지 +24%는 상대적으로 짧은 거리라 실적·수급이 받쳐주면 몇 주 내 돌파도 가능(반대로도 급함).
- 도구의 차트는 실제 일봉(과거)에 예상(미래)을 이어 붙이고, 변동 밴드를 실제 변동성 기반으로 넓혔습니다.

## 수급 — 외국인·기관·개인

- 외국인: 상반기 하이닉스 57조 순매도(6/29 하루 7.7조 역대급), 보유율 50.4%로 3년래 최저 → 급락 주범·오버행. 단, 패시브 리밸런싱 성격이라 대부분 마무리 → 재유입 가능성.
- 개인: 상반기 40.8조 순매수(빚투 포함) → 주가 지지.
- 기관: 14.9조 순매수.
- ADR(7/10): 신주 2.5% 희석 + 한국ETF 자금 이동 = 단기 노이즈. 큰 패시브 유입(나스닥100)은 12월, SOX는 2027년.

해석: 전고점 돌파가 늦어질 수 있는 이유 = 외국인 오버행. 빨라질 촉매 = 7/23 실적 → 외국인 재유입 → 12월 나스닥100 편입. 회복 속도(빠름/보통/느림)로 돌파 시점을 조절할 수 있으며, 기본(빠름·PER10)에서는 전고점 300만 재돌파가 약 9주 후(9월경)로 계산됩니다.

## 결론 (안 흔들리는 전략)

이 종목은 하루 10~15% 변동해 자주 매매하면 포지션을 잃기 쉽습니다. 평단(226만)이 낮아 손해 위험은 작고 상승 여지가 큰 자리이므로:

- 코어 28주(3분의 2)는 리레이팅 끝까지 보유 (목표 430만~500만)
- 나머지 14주만 전고점 300만 회복 시(오를 때만) 절반 덜어 이익 확보
- 손절은 평단 근처에 걸지 않기 (7/2 218만 급락 후 바로 반등 — 바닥에 팔릴 위험). 팔 거면 오를 때만.
