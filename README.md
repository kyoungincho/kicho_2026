# kicho_2026
더 나은 인생을 위한 설계시작 2026년

## ⚽ 대한민국 32강 진출 시나리오 계산기

2026 FIFA 월드컵(미국·캐나다·멕시코) 방식에 맞춰 **대한민국의 32강 진출 가능성**을
계산해 주는 간단한 웹 페이지입니다. 별도 설치 없이 브라우저에서 바로 동작합니다.

### 사용법
`index.html`을 브라우저로 열면 됩니다. (로컬 서버 예시: `python3 -m http.server`)

### 기능
- **2026 대회 방식 안내**: 48개국 · 12개 조 · 각 조 1·2위 + 3위 중 상위 8팀이 32강 진출
- **우리 조 계산기**: 4팀 6경기 스코어를 입력하면 순위표와 진출 여부를 즉시 계산
- **3위 경쟁 비교**: 3위로 마쳤을 때 다른 조 3위 팀들과 비교해 상위 8위 안에 드는지 확인

### 진출 조건 요약
1. **조 1·2위** → 32강 자동 진출
2. **조 3위** → 12개 조 3위 팀 중 성적(승점 → 골득실 → 득점) 상위 **8위** 안에 들면 진출

### 구성
- `index.html` · `styles.css` · `app.js` (의존성 없는 정적 페이지)
